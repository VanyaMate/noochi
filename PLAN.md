## Фаза 6. Фронтенд (`apps/web`, Vite+React+TS+Tailwind)
- [x] Дизайн-токены: тёплая пастель с оранжевым «ламповым» уклоном (cream/parchment/latte + терракота/honey), зелёный (sage) только как мелкий семантический акцент (уровни, «known», ok-тост), мягкие тени и почти незаметный оранжевый фон-градиент (cream `#fcf7f2`, альфы 0.07–0.13); i18n ru/en
- [x] Роуты, auth-экраны, layout «мессенджер» (список чатов + лента + composer)
- [x] Каталог персонажей по уровням A1–C2 с фильтрами
- [~] Чат: стриминг по WS, «печатает», аватары-градиенты, звуки — код и WS-доставка проверены; стрим ответа нужен реальный OpenRouter-ключ
- [x] Popup разбора: выделение → превью с кнопкой «🔍 Разобрать», запрос только по клику; внутри перевод/почему/аналоги/грамматика и «к изучению»
- [x] Popup прижимается к выделению: снизу → сверху → сбоку → по центру, с клампом во вьюпорт (замер через offsetWidth/Height, чтобы pop-in scale не сбивал позицию)
- [x] Лента чата: колонка до 720px (шапка/сообщения/composer выровнены), переключатель раскладки ⇄ «бот слева / мои справа» ↔ «все слева», выбор в localStorage
- [x] Фикс дублей после стрима: черновики ответов живут в том же кеш-объекте треда, что и сообщения, — «добавить сохранённое сообщение» и «убрать его черновик» применяются в один рендер; черновик сбрасывается по `Message.requestId` (дублей ровно 0 кадров, проверено наблюдателем DOM-переходов)
- [x] Разбор выделенного: терпеливый парсинг JSON от мелких моделей (```` ```json ````-обёртки, сырые переводы строк внутри значений, висячие запятые, обрезанный хвост, массив строк вместо объектов, `B1 (intermediate)`) + автоповтор запроса на сервере с более жёсткой подсказкой; если и тогда мусор — `AI_UNPARSABLE` и в попапе кнопка «🔁 Попробовать ещё раз»
- [x] Проверка своего сообщения после отправки → метка статуса у сообщения: «Проверяю…» → «✓ Всё чисто» / «⚠ Ошибки · N»; клик открывает CheckPopup (цитата → исправление, тип ошибки, «Как звучит лучше»)
- [x] Проверка и ответ — одним запросом к нейронке: персонаж отдаёт текст плюс машинный блок после маркера `<<<CHECK>>>`, `createCheckGate` стримит только прозу и разбирает хвост в `AiCheckRes`; отдельного `svc.ai.check` в чате больше нет (одно завершение модели на сообщение)
- [x] Результат проверки сохраняется в строке сообщения (`messages.check jsonb`) и приходит вместе с историей — после перезагрузки страницы метка и попап на месте; локально держатся только два состояния, которых не бывает в БД («проверяю», «не удалось»)
- [x] CheckPopup: у каждого замечания кнопка «🌱» → карточка «к изучению» (тип `grammar` → «Грамматика», одно слово → «Слова», иначе «Фраза»); кнопка гаснет на «✓»
- [x] Composer: кнопка «🌐» → форма «напиши по-своему → перевод на язык диалога» (`svc.ai.translate`, уровень персонажа задаёт регистр), результат можно вставить в черновик
- [x] Персонажи: клик по карточке больше не открывает диалог — сначала модалка с описанием (персона, стартовая реплика, стиль, интересы); текст внутри размечен `data-explain`, поэтому выделение → тот же разбор, что и в чате; диалог — только по «💬 Начать диалог»
- [x] Плавный размер всплывающих окон: анимируется внешняя коробка (width/height/top/left, 220ms), а содержимое меряется `ResizeObserver`-ом по `offsetWidth/offsetHeight` — замер не попадает в кадры перехода; то же и у модалок (высота стартует заново для каждой открытой)
- [x] Страница «🔍 Разборы»: каждый разбор выделенного пишется в таблицу `explains` и хранится с контекстом и датой; карточка → модалка с результатом и «🗑 Удалить разбор»
- [x] Радио: 4-я станция «Cozy Loop» генерируется на месте (WebAudio: коричневый шум + тёплый пад + LFO-дыхание), играет без сети и без 403 — SomaFM ключа не требует, там зеркало отдаёт 403 части клиентов, поэтому и перебор зеркал, и локальная станция
- [x] Метка проверки — в одной строке со временем сообщения и тем же кеглем (10px); цвет по серьёзности: чисто — серый, косметика — оранжево-серый, ошибка — красно-серый, несколько/грубых — красный (вес: grammar/word = 2, spelling/punctuation = 1, style = 0)
- [x] Ошибка разбора показывается один раз: эффект запроса больше не перезапускается на каждом рендере (нестабильные `t`/user в зависимостях давали мерцание и бесконечные автоповторы); заголовок различает «лимит/нет ключа» и «модель отдала мусор»
- [x] Меню: «Подписки» убраны из сайдбара — вход по клику на бейдж тарифа в строке профиля и с самой страницы профиля
- [x] Время у сообщений (HH:MM под пузырём и у системных фраз)
- [x] Страницы «Слова», «Грамматика», «Повторение» (SRS-режим, карточка → оценка → готово)
- [x] Профиль: API-ключ (сохранение/удаление), модель — свободный ввод + datalist подсказок (можно вписать любой id, в т.ч. `:free`), языки, звук, лимиты плана
